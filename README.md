# SpendWise AI 💸

SpendWise AI е уеб приложение за следене на личните разходи. Потребителят задава месечен бюджет, добавя разходите си ръчно или като снима касовата бележка, а изкуственият интелект сам разпознава сумата, магазина и категорията. Приложението показва графики на разходите, предупреждава при превишен бюджет и дава персонални съвети за спестяване.
