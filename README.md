# SpendWise AI 💸

Уеб приложение за следене на личните разходи. Изкуственият интелект (Google Gemini) сам категоризира разходите, разчита касови бележки от снимка и дава съвети за спестяване.

## Функции

- **Месечен бюджет** – задаване на лимит, лента за прогреса и предупреждение при превишаване
- **Ръчно добавяне на разходи** – категорията се определя автоматично от AI, ако не е избрана
- **Сканиране на касови бележки** – снимка от телефона → магазин, сума, дата и категория
- **Графики** – разпределение по категории и разходи по дни / седмици
- **AI съвети** – анализ на навиците на харчене за месеца
- **Списък с разходи** – търсене и изтриване

## Стартиране

### 1. Клониране

```bash
git clone https://github.com/Yoana-Georgieva/SpendWise-AI.git
cd SpendWise-AI
```

### 2. API ключ

Създай файл `backend/.env` със съдържание:

```
GEMINI_API_KEY=твоят_ключ
```

> ⚠️ Файлът `.env` е в `.gitignore` – никога не го качвай в GitHub.

### 3. Пускане

**Бърз начин (Windows):** двоен клик на `frontend/start.bat` – инсталира библиотеките (първия път), пуска сървъра и отваря приложението.

**Ръчно:**

```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install fastapi uvicorn python-dotenv google-genai pillow python-multipart
uvicorn main:app --reload
```

След това отвори `frontend/index.html` в браузъра.

- Сървър: http://127.0.0.1:8000
- Документация на API: http://127.0.0.1:8000/docs

## API

| Метод  | Адрес                       | Описание                               |
|--------|-----------------------------|----------------------------------------|
| GET    | `/expenses`                 | Всички разходи                         |
| POST   | `/expenses`                 | Нов разход (`category: ""` → AI)       |
| DELETE | `/expenses/{id}`            | Изтриване на разход                    |
| POST   | `/scan-receipt`             | Сканиране на бележка (FormData `file`) |
| POST   | `/budget`                   | Задаване на месечен бюджет             |
| GET    | `/budget/{ГГГГ-ММ}`         | Статус на бюджета + категории          |
| GET    | `/analytics/periods`        | Разходи по `day` / `week` / `month`    |
| GET    | `/insights/{ГГГГ-ММ}`       | AI анализ и съвети                     |
